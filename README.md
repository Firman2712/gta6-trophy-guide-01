Leonida Ledger is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI.
It pairs a cited step-by-step guide for every trophy with a checklist that saves progress in the browser, a four-stage roadmap to the platinum, missable-trophy warnings, and a spoiler-free mode that hides hidden trophies until you choose to reveal them.

## Run it

```sh
node serve.ts
```
